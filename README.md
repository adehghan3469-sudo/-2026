# از بابامنیر چه خبر 🌾

اپلیکیشن هواشناسی و کشاورزی مخصوص منطقه بابامنیر (استان فارس)

## ویژگی‌ها
- خلاصه وضعیت هوا و ET₀
- دستیار هوشمند کشاورزی با اتصال به Grok
- پایش ماهواره‌ای شاخص NDVI
- منوی کامل برای توسعه بعدی

## نحوه اجرا محلی
```bash
pip install -r requirements.txt
streamlit run app.py
```

## تنظیم Secrets
فایل `.streamlit/secrets.toml` را با کلیدهای واقعی پر کنید.
